# Nicolas Cejas - Personal Portfolio

## Overview
A modern, minimalist personal presentation card and portfolio built to showcase my professional experience and backend-focused skill set. Originally developed as a learning project to explore React hooks, it has been fully migrated to modern web standards utilizing the newest Next.js capabilities.

### Features 
- **Digital Business Card:** Core profile representation and quick links to social platforms
- **Interactive CV:** Detailed timeline of my professional journey and projects (`/cv`)
- **Dynamic Theme:** Built-in seamless switching between Dark and Light appearances
- **About Me Section:** A glimpse into my background, hobbies, and personal life (`/about`)

### Built With 
- **Framework:** [Next.js 15](https://nextjs.org/) (App Router & React Server Components)
- **Language:** TypeScript (Strict Type Safety)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **UI Architecture:** [Shadcn UI](https://ui.shadcn.com/) & [Radix UI](https://www.radix-ui.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Package Manager:** `pnpm`

## Getting Started

First, install the required dependencies:

```bash
pnpm install
```

Second, run the development server:

```bash
pnpm run dev
```

Finally, open [http://localhost:3000](http://localhost:3000) with your browser to see the result locally.
